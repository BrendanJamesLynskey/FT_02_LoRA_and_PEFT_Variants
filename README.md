# FT 02 — LoRA and PEFT Variants

A technical deep-dive into Low-Rank Adaptation and the family of parameter-efficient fine-tuning methods it spawned: the rank decomposition mathematics, target-module selection rationale, hyperparameter sensitivity (rank, alpha, dropout), QLoRA's 4-bit NF4 quantisation, DoRA's magnitude&ndash;direction decomposition, IA3's even-smaller perturbations, and practical adapter merging and multi-LoRA serving architectures.
